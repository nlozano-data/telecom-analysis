# telecom-analysis
Análisis exploratorio de datos para ConnectaTel, enfocado en la limpieza y calidad de los datos, estadísticas descriptivas, detección de valores atípicos y segmentación de clientes por edad y nivel de uso. Desarrollado con Python, Pandas, NumPy, Matplotlib y Seaborn para identificar patrones y generar recomendaciones de negocio.
